# Suffer Lab (phone)

The phone page of Andy's cycling analysis, served by GitHub Pages.  Plain HTML, CSS and JavaScript; no build step.

This repository holds code only: no ride data, gym data, physiology figures or token.  The page reads a separate private data repository with a read-only token that is pasted into the page's Settings and kept on the phone.

The files here are published from the private `cycling-app` repository (`phone/` and the Mac dashboard's shared files) by `mac/publish-phone.command`.  Change them there, not here.
